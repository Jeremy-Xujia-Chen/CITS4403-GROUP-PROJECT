# Reproduce calibration

Use Python 3.10.18 and root requirements-project.txt. Run Reproduce-Calibration.ps1 with -Python pointing at that interpreter; add -Fresh to back up simulator checkpoints and run actual model cases again. Research/calibrate_15y.py supplies separate 600x15 validation. After fitting, regenerate research tables and the report rather than reusing historical conclusions.

Detailed fit methods and evidence: reliable-calibration/calibration-report.md.
Input sources and definitions: raw-rebuild/source-manifest.json.
No calibration command publishes to GitHub.
